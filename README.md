# Vaishnav K — Data Engineer Portfolio

This repository contains only the source files for the professional portfolio website.

- **Portfolio site:** https://vaishnav-k.github.io/data-engineer-portfolio/
- **Featured banking data engineering project:** https://github.com/Vaishnav-K/ai-enhanced-banking-data-platform

## Website structure

- `site/index.html` — page content
- `site/styles.css` — responsive styling
- `site/script.js` — interactions and demo visualizations
- `site/assets/` — profile image and other static assets
- `site/Vaishnav-K-Resume.pdf` — resume linked from the site
- `.github/workflows/deploy.yml` — GitHub Pages deployment workflow

The workflow refreshes the synthetic dataset display metrics from the public CSV inputs in the separate banking project and publishes the `site/` directory through GitHub Pages.
